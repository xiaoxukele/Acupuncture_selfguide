# 可转发的离线版

下载本目录内 `Acupuncture_selfguide-offline-1.0.0.zip`，完整解压后双击 `打开网页.html`。不需要安装开发环境、运行命令或登录。

`assets`、`app.js`、`styles.css` 要与 HTML 一起保留。搜索与图谱等功能离线可用，外部参考文献链接需要联网。优先使用电脑浏览器，部分手机文件管理器不支持运行本地网页脚本。

压缩包内有使用说明及逐文件 SHA-256 校验表。收藏只保存在接收者当前浏览器，不随压缩包转移。医学内容仍为待专业复核的学习示意。

维护者重新打包：先在项目根目录运行 `npm run build`，再运行 `python scripts/package_offline.py`。离线分发不包含依赖目录、Git 数据或站点登录信息。
